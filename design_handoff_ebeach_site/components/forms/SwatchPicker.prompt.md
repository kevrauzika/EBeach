One-line: circular colour swatches for the product configurator.

```jsx
<SwatchPicker label="Armação" value={frame} onChange={setFrame}
  options={[{value:'abissal',label:'Abissal',swatch:'#06222D'}]} />
```

Gradient swatch values are allowed here (mirrored / degradê lenses) — this is the one exception to the no-gradient rule.
