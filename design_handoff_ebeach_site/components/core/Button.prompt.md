One-line: the brand's pill-shaped call to action — uppercase, wide-tracked, never rounded-rectangle.

```jsx
<Button variant="solid" size="lg" magnetic>Adicionar à sacola</Button>
<Button variant="outline">Ver coleção</Button>
<Button variant="outlineDark" size="sm">Assinar</Button>
```

Variants: `solid` (sun #FF8A3D, one per view), `sea` (turquoise, secondary), `outline`/`ghost` on sand, `onDark`/`outlineDark` on abyssal. Labels are 1–3 words, uppercase, Portuguese. Never add a drop shadow.
